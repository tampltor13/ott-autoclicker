v1.0.60 — Freeze Detection: zero-baseline protection + max retry limit
-----------------------------------------------------------------------
- Skip-if-zero-on-first-sample: if baseline currentTime=0.0 (video not started yet),
  freeze detection skips that cycle and retries — up to 3 times before giving up
- Max retry limit: if freeze recovery runs 3 consecutive times and currentTime stays 0.0
  (video unresponsive), freeze detection stops automatically with a warning
- Prevents infinite refresh loops when video player fails to load or currentTime is unavailable
- Both counters reset to 0 whenever a healthy currentTime (>0.0) is detected
